CODEX_LMS: one download, three ways to open it

  Double-click  "Start CODEX_LMS.command"   and choose.
  Mac app       CODEX_LMS.app               (first time: right-click > Open, or System Settings > Privacy & Security > Open Anyway)
  Browser       CODEX_LMS.html              (double-click; works offline)
  Terminal      node CODEX_LMS.html         (needs Node 18+: brew install node)

CODEX_LMS.html is the same file for the browser and the terminal. If macOS blocks the .command file the first time,
right-click it and choose Open.
